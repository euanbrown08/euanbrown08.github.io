SATRADAR

Every active satellite in orbit, around sixteen thousand of them, propagated live in your browser. Filter by constellation or orbit, or see what's overhead where you are.

Open SATRADAR →

Every active satellite in orbit, live in a browser tab. Each object is described by eight numbers; propagating all sixteen thousand of them takes about nine milliseconds in a web worker, so there is no backend and nothing to call.

I built it because in this domain a wrong number looks exactly like a right one, so most of the work went into being able to tell the difference.

TypeScript · three.js · SGP4 via satellite.js · Web Worker · static, no backend · 188 tests · refreshed daily by GitHub Actions
